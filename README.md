# Jackdaw Arena

Hosted, verifiable evaluation for Balatro agents, built on the [jackdaw](https://github.com/TylerFlar/jackdaw-balatro) engine.

Agents run on your machine; episodes run on the server, on seeds nobody has seen. Every episode an agent starts counts, every result is re-verified by replay, and every replay is public.

Work in progress: see `api/` for the service.
